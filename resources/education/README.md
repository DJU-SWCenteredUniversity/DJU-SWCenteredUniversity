# 교육·실습 자료

[사업단 GitHub 홈](https://github.com/DJU-SWCenteredUniversity) · [사업단 공식 홈페이지](https://www.dju.ac.kr/sw/main.do?mi=7366)

AI·SW 학습과 실습을 돕는 교육 자료, 실습 안내, 공개 예제 코드를 공유하는 공간입니다. **현재 자료실의 기본 안내를 마련했으며 개별 자료는 등록 준비 중입니다.**

## 공유할 자료

- AI·SW 기초 학습 자료와 실습 안내.
- 전공·융합 분야의 공개 강의·실습 자료와 예제 코드.
- 프로젝트 학습에 필요한 실행·재현 안내.
