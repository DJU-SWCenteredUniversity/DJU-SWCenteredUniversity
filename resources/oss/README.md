# 오픈소스 자료

[사업단 GitHub 홈](https://github.com/DJU-SWCenteredUniversity) · [사업단 공식 홈페이지](https://www.dju.ac.kr/sw/main.do?mi=7366)

공개 프로젝트와 소스코드를 찾아보고, 학습과 프로젝트에 활용할 수 있는 OSS 자료를 공유합니다. **개별 OSS 교육 자료와 공개 프로젝트 목록은 순차적으로 등록합니다.**

## 바로가기

| 자료 | 활용 |
|---|---|
| [AI·OSS 동아리 관리](https://github.com/DJU-SWCenteredUniversity/ai-oss-clubs) | 동아리별 공개 프로젝트와 활동 |
| [캡스톤디자인 결과물](https://github.com/DJU-SWCenteredUniversity/capstone-archive) | 프로젝트 소개·코드·실행·시연 자료 |
| [학생 프로젝트 공통 템플릿](https://github.com/DJU-SWCenteredUniversity/sw-project-template) | 코드·문서·OSS 활용 기록을 정리하는 기본 구조 |

## 공개 프로젝트·활용 자료 목록

자료를 활용할 때 해당 저장소의 README, 실행 방법, 출처와 라이선스 안내를 함께 확인합니다. 프로젝트의 OSS 사용 기록은 공통 템플릿의 `docs/oss-license-check.md`에 정리할 수 있습니다.
