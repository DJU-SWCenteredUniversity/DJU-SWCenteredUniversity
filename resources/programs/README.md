# 교육프로그램 자료

[사업단 GitHub 홈](https://github.com/DJU-SWCenteredUniversity) · [사업단 공식 홈페이지](https://www.dju.ac.kr/sw/main.do?mi=7366)

사업단 프로그램별 안내와 공개 가능한 운영 자료·교육 성과를 공유하는 공간입니다. **현재 기본 안내를 마련했으며 프로그램별 자료는 등록 준비 중입니다.**

## 공유할 자료

- 프로그램 소개와 공식 참여 안내 링크.
- 공개 가능한 교육·활동 자료와 참가자용 안내.
- 프로그램별 프로젝트·발표·교육 성과의 공개 자료.

|---|---|---|---|
