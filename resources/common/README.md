# 공통 서식·GitHub 활용

[사업단 GitHub 홈](https://github.com/DJU-SWCenteredUniversity) · [사업단 공식 홈페이지](https://www.dju.ac.kr/sw/main.do?mi=7366)

학생 프로젝트를 시작하고 계획·활동·결과물을 정리할 때 사용하는 공통 자료입니다.

## 바로 사용할 수 있는 템플릿

[학생 프로젝트 공통 템플릿](https://github.com/DJU-SWCenteredUniversity/sw-project-template)에는 코드·문서·데이터·보고서 폴더와 작성 양식이 준비되어 있습니다.

- **GitHub에서 팀 저장소 생성:** Use this template → Create a new repository.
- **Git 설치 없이 시작:** Code → Download ZIP → 압축 풀기.
- **clone 또는 스크립트로 시작:** 저장소 README의 학생 빠른 시작 안내를 따릅니다.
