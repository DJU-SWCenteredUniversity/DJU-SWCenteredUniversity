## 사업단 소개

대전대학교 SW중심대학사업단은 모든 학생의 AI·SW 기초역량을 높이고, 전공 전문성과 융합 역량을 갖춘 인재를 양성합니다. 산업 수요를 반영한 교육과 지역·기업과의 협력을 통해 배움이 현장의 문제 해결로 이어지도록 지원합니다.

대전대학교의 ACE 교육모델을 바탕으로 기초·전공·융합교육을 연결하고, 한의학과 헬스케어 등 대학의 강점 분야에 AI·SW를 접목하여 지역과 산업의 변화에 기여하고자 합니다.

## 함께 배우고 기록하는 GitHub

이 공간은 대전대학교 SW중심대학사업단의 교육 자료와 학생 프로젝트를 함께 기록하고 공유하기 위해 마련했습니다.

- **배움의 기록** — 학습 자료와 실습 예제를 정리합니다.
- **프로젝트 협업** — AI·OSS 동아리와 학생 프로젝트의 코드·문서·개선 과정을 기록합니다.
- **지식의 공유** — 오픈소스 활동과 프로젝트 경험을 나누며 함께 성장합니다.

교육 프로그램과 참여 안내는 [사업단 공식 홈페이지](https://www.dju.ac.kr/sw/main.do?mi=7366)에서 확인해 주세요.
